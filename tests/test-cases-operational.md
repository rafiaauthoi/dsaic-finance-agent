# Rules Checker Test Cases: Operational Proposals

This test set covers OPS-01 through OPS-07 from section 4.2, [Operational funding in detail][operational-rules], plus PRO-12 from the assigned issue. It uses the five-column format of [test-cases-event.md](test-cases-event.md).

Each passing example should produce no violation of the named rule, and each failing example should produce the message in the last column. Evaluate labeled subcases separately. Examples are self-contained; other applicable rules may produce additional warnings.

All clubs, people, vendors, dates, records, and scenario amounts are fictional. Policy limits come from the reference unless explicitly labeled as a test fixture. Assume all other eligibility and submission requirements are met. **Manual check** identifies facts that cannot be established from the proposal sheet alone. The external evidence described in a case is fictional test input, not something the checker may infer from the sheet; a person must verify it before deciding.

**PRO-12 source note:** The assigned issue explicitly states that subscriptions and memberships are never funded. The available v4 reference dated 2026-09-27 stops at PRO-11 and still records subscription uncertainty in section 4.2 and BS-06. This row follows the issue's requirement. Its link points to section 4.6, the general prohibitions section; confirm PRO-12's wording and placement against the updated project reference before merging.

## Notes for reviewing the cases

- **OPS-01:** A nonstandard category requires justification; the rule does not automatically ban every expense outside the three usual categories.
- **OPS-05 is permissive.** There is no invalid proposal based solely on equipment being 100% of the budget. The failing column therefore describes an incorrect checker rejection. An arithmetic inconsistency should be tested under a separate totals check, not presented as a new OPS-05 restriction.
- **OPS-06:** The $250 limit is cumulative across the fiscal year, not a fresh allowance for each request. Clothing is excluded from this promotional-item cap; other applicable rules still apply.
- **OPS-07:** This is a post-approval spending check. The proposal sheet cannot establish the funding letter or a later authorization.
