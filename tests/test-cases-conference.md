# Rules Checker Test Cases: Conference Proposals

This test set covers CNF-01 through CNF-08 from section 4.3, [Conference funding in detail][conference-rules], in the canonical WSA rules reference. It uses the five-column format of [test-cases-event.md](test-cases-event.md).

Each passing example should produce no violation of the named rule, and each failing example should produce the message in the last column. Evaluate labeled subcases separately. Examples are self-contained; other applicable rules may produce additional warnings.

All clubs, people, vendors, dates, records, and scenario amounts are fictional. Policy limits come from the reference unless explicitly labeled as a test fixture. Assume all other eligibility and submission requirements are met. **Manual check** identifies facts that cannot be established from the proposal sheet alone. The external evidence described in a case is fictional test input, not something the checker may infer from the sheet; a person must verify it before deciding.

## Notes for reviewing the cases

- **CNF-03:** `<synthetic-WIN-A>` stands for a fabricated identifier in the test fixture, not a real student's WIN. These cases test required-field presence and evidence; they do not specify WIN-format validation. Do not substitute real attendee details or records into this public file.
- **CNF-04:** The calendar is invented. Deliberation is Monday, 03/01/2027; Friday, 03/12/2027 is business day 9 and Monday, 03/15/2027 is business day 10, assuming no university closures. Use the actual university calendar for a real request.
- **CNF-06:** $0.50 per mile is an invented policy input used only to test the comparison. It is not a statement of WMU's current mileage rate and must not become a production default.
- **CNF-07 and CNF-08:** These checks involve reimbursement or changes after allocation, so the original proposal sheet is insufficient.
- **CNF-08:** Neither rescheduling nor cancellation gives the club automatic authority to move money or restore its cap. WSAAC retains discretion; do not infer how much can be restored when some funds were spent.
