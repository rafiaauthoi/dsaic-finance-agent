# Rules Checker Test Cases: Common Proposal Mistakes

This test set covers SUB-23 through SUB-30 from section 6.5, [Common mistakes that get proposals rejected][common-mistakes], in the canonical WSA rules reference. The same rule IDs appear in [wsa-club-finance-rules.yaml](../docs/wsa-guidelines/wsa-club-finance-rules.yaml).

Each row contains a passing example and a failing example for the named rule. The checker should report the message in the last column for the failing example and no violation of that rule for the passing example. Some mistakes overlap with other rules, so additional applicable warnings are allowed.

All examples, organizations, representatives, vendors, email addresses, and amounts are invented. For the identity examples, assume a synthetic registration record lists the full name as **Example Club** and the representative as **Representative A**. The email address is a fictional test value, not a real contact. Unless an example states otherwise, assume the rest of the proposal and submission is complete and correct. File-level examples describe the workbook or submission rather than a line item.

| Rule ID | Rule | Follows the rule | Breaks the rule | What the checker should say |
| --- | --- | --- | --- | --- |
| [SUB-23][common-mistakes] | Upload an actual proposal file; a link alone is insufficient. | The completed proposal workbook is uploaded as an .xlsx file to the submission dropbox. | Only a Google Drive link is supplied; no proposal file is uploaded. | "No proposal file was uploaded. Upload the completed .xlsx file to the submission dropbox; a link alone is not a submission." |
| [SUB-24][common-mistakes] | Use the current official template with its original formatting. | The proposal uses the current official template for its budget type, with the original layout and total formulas unchanged. | The proposal uses an outdated official template instead of the current required version. | "This proposal uses an outdated template. Transfer your entries to the current official template for the selected budget type." |
| [SUB-25][common-mistakes] | Describe the requested item clearly and identify its vendor. | Item Requesting: Dry-erase markers; Vendor Name: Example Supply Shop; Cost: $20; Amount Requesting: $20. | Item Requesting: Supplies; Vendor Name: **[blank]**; Cost: $20; Amount Requesting: $20. | "Item 'Supplies' is too vague and is missing a vendor name. State what you are buying and enter the vendor's business name." |
| [SUB-26][common-mistakes] | Every requested amount needs a matching item description. | Item Requesting: Dry-erase markers; Vendor Name: Example Supply Shop; Cost: $20; Amount Requesting: $20. | Item Requesting: **[blank]**; Vendor Name: Example Supply Shop; Cost: $20; Amount Requesting: $20. | "A line requests $20 but has no item description. Fill in Item Requesting to explain what this amount is for, or remove the request." |
| [SUB-27][common-mistakes] | Complete the identity fields: full RSO name, valid contact email, and typed signature. | Full RSO Name: Example Club; RSO Representative: Representative A; Contact Email: `representative-a@example.edu`; Typed Signature: Representative A. | Full RSO Name: Example Club; RSO Representative: Representative A; Contact Email: `representative-a@example.edu`; Typed Signature: **[blank]**. | "Typed Signature is missing. Enter the representative's typed signature in the proposal's identity section." |
| [SUB-28][common-mistakes] | Each requested line item needs a vendor and an Amount Requesting. | Item Requesting: Poster printing; Vendor Name: Example Print Shop; Cost: $40; Amount Requesting: $40. | Item Requesting: Poster printing; Vendor Name: Example Print Shop; Cost: $40; Amount Requesting: **[blank]**. | "Item 'Poster printing' is missing Amount Requesting. Enter the amount you want WSAAC to fund." |
| [SUB-29][common-mistakes] | Use one worksheet per workbook and one proposal per file. | An .xlsx workbook contains one worksheet named Proposal and one budget proposal. | An .xlsx workbook contains two worksheets, Proposal A and Proposal B, each holding a separate budget proposal. | "This workbook contains 2 worksheets. Submit each proposal as a separate .xlsx file with exactly one worksheet." |
| [SUB-30][common-mistakes] | Fill in the template's input cells; a screenshot cannot replace the proposal. | Request details are entered in the template's input cells. A supporting vendor-quote screenshot is attached outside the colored border. | The template's input cells are empty; a screenshot of the completed proposal is pasted into the workbook instead. | "The proposal is supplied as a screenshot. Enter the request in the template's input cells; a pasted image cannot replace a completed proposal." |

**SUB-30 clarification:** Supporting screenshots, vendor images, and quotes outside the template's colored border are permitted under SUB-21. The SUB-30 failure is using a screenshot instead of filling in the proposal, not merely including a supporting image.
