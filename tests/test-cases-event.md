# Rules Checker Test Cases: Event Proposals

This test set covers EVT-01 through EVT-17 from section 4.1, [Event funding in detail][event-rules], in the canonical WSA rules reference. It uses the same five-column format as [test-cases.md](test-cases.md).

For each rule, the passing example should produce no violation of that rule, and the failing example should produce the message in the last column. Some mistakes overlap with other rules, so additional applicable warnings are allowed. Where a row contains labeled subcases, evaluate them separately.

All clubs, people, vendors, event scenarios, dates, attendance figures, and example costs are fictional. Policy limits are taken from the reference. Assume each example concerns **Example Club**, every vendor name beginning with **Example** is invented, and all other eligibility and submission requirements are met unless stated otherwise.

**Manual check** means the proposal sheet alone cannot establish the facts needed for a decision. The checker should flag the missing verification for a person. The external evidence described in the examples is part of the fictional test scenario; it must not be assumed from the sheet. For these rows, the pass or fail outcome is established after that evidence is reviewed. Numeric messages assume the stated inputs have been verified.

## Notes for reviewing the cases

- **EVT-02 is a location restriction, not a numerical cap.** Its failing example changes the event location while keeping the food request within the per-attendee limit.
- **EVT-03 has two independent monetary limits.** Its rate and total subcases test each limit separately. Membership still requires a person to verify facts outside the proposal sheet.
- **EVT-06 uses the $250 fiscal-year cap from the September 2026 bylaws.** The older $200 figure mentioned in the reference is superseded. The examples test a cumulative total, and their banners are retained for club use rather than given away.
- **EVT-12 uses an invented calendar fixture.** Deliberation is Monday, 03/01/2027. Count weekdays starting the following day, excluding weekends and assuming no university holidays or closures in this fixture. Friday, 03/12/2027 is business day 9; Monday, 03/15/2027 is business day 10. A real decision needs the actual university calendar.
- **EVT-15 requires review of the service scope.** Breaking an all-inclusive package into several listed prices does not, by itself, establish that the underlying service follows the rule.
- **EVT-17 tests deliberate inflation supported by external evidence.** A lower actual turnout than a reasonable estimate does not, by itself, establish that an estimate was inflated. Its failing proposal satisfies the arithmetic in EVT-01 using its declared count, demonstrating why attendance credibility needs a separate check.
